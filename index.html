Recursão &
Árvores Binárias Balanceadas (AVL)

Uma visão aprofundada sobre recursão em árvores, balanceamento dinâmico, rotações, travessias e remoção eficiente em tempo O(log n).

Conceito Base

A Essência Recursiva de uma Árvore

Uma árvore é uma estrutura inerentemente recursiva: cada nó é a raiz de duas subárvores.

🎯

Caso Base (Condição de Parada)

Se o nó atual é nulo (node == null), a recursão atinge o fundo e inicia o desempilhamento retornando 0 ou um nó sentinela.

🔄

Passo Recursivo (Dividir e Conquistar)

O problema na raiz se reduz a resolver o mesmo problema na subárvore esquerda e na subárvore direita, combinando os resultados no retorno da pilha de execução.

Por que Balancear?

O Problema da Degeneração em BST

Em uma BST tradicional, inserções ordenadas degradam a busca para O(n). A AVL garante O(log n).

📉

Degeneração em Lista

Inserir [1, 2, 3, 4, 5] cria uma linha reta com altura n. Buscar custa tempo linear.

⚖️

A Solução AVL (1962)

Criada por Adelson-Velsky e Landis. Uma BST auto-balanceada pela diferença máxima de 1 entre alturas das subárvores.

⚡

Garantia Rigorosa

Mesmo no pior caso de inserção ou remoção, operações de busca, inclusão e exclusão rodam em estrito O(log n).

Métricas da Árvore

Altura & Fator de Balanceamento (FB)

Toda decisão na AVL deriva do cálculo da altura dos filhos e do fator de balanceamento resultante.

FB(nó) = Altura(Subárvore Esquerda) - Altura(Subárvore Direita)
✓

Nó Balanceado

O nó é balanceado se FB ∈ {-1, 0, +1}. Nenhuma rotação é necessária.

⚠️

Desbalanceado à Esquerda

Se FB > +1 (+2), o peso está no ramo esquerdo. Exige rotação à direita (simples ou dupla).

⚠️

Desbalanceado à Direita

Se FB < -1 (-2), o peso está no ramo direito. Exige rotação à esquerda (simples ou dupla).

Lógica de Decisão

Retornando o Tipo de Rotação

A rotação adequada é determinada pelo sinal do FB do nó atual combinado com o sinal do FB de seu filho.

⟳

Direita Simples (LL)

FB(nó) > 1 && FB(esq) ≥ 0
Inserção no ramo esquerdo do filho esquerdo.

⟲

Esquerda Simples (RR)

FB(nó) < -1 && FB(dir) ≤ 0
Inserção no ramo direito do filho direito.

⤹⤸

Dupla Direita (LR)

FB(nó) > 1 && FB(esq) < 0
Rotaciona o filho à esquerda, depois o pai à direita.

⤸⤹

Dupla Esquerda (RL)

FB(nó) < -1 && FB(dir) > 0
Rotaciona o filho à direita, depois o pai à esquerda.

Implementação

Rotações Básicas em Tempo O(1)

Reorganização estrita de ponteiros e atualização de alturas locais.

avl_rotations.ts
// Rotação Simples à Direita (Right Rotation) function rotateRight(y: Node): Node { const x = y.left!; const T2 = x.right; x.right = y; // y desce e vira filho direito de x y.left = T2; // subárvore T2 é adotada como filha esquerda de y y.height = Math.max(height(y.left), height(y.right)) + 1; x.height = Math.max(height(x.left), height(x.right)) + 1; return x; // x é a nova raiz da subárvore }
Inserção

Método de Inserção Recursiva

Desce até as folhas via recursão, insere o nó e rebalanceia na volta do desempilhamento.

Atualiza a altura do ancestral node.height = 1 + Math.max(height(node.left), height(node.right)); // 3. Travessias Recursivas

Impressão: In-Ordem, Pré-Ordem & Pós-Ordem

Três formas elegantes de percorrer todos os nós através de recursão com O(n).

📊

In-Ordem (Em Ordem)

Esq → Raiz → Dir

Imprime todos os elementos em ordem crescente estrita. Essencial para validação e ordenação.

🌳

Pré-Ordem

Raiz → Esq → Dir

Visita o pai antes dos filhos. Ideal para serializar/clonar a árvore preservando sua estrutura original.

📦

Pós-Ordem

Esq → Dir → Raiz

Processa os filhos antes do pai. Padrão obrigatório para liberação de memória (delete) e cálculo bottom-up.

Remoção

Remoção de Nós em Árvore AVL

Combina a exclusão padrão de BST com rebalanceamento propagado até a raiz.

1

Nó Folha / 1 Filho

Se não tem filhos, simplesmente remove. Se tem 1 único filho, substitui o nó por esse filho direto.

2

Nó com 2 Filhos

Localiza o sucessor in-order (menor valor da subárvore direita), copia seu valor e remove o sucessor recursivamente.

3

Rebalanceamento

Ao desempilhar as chamadas recursivas, recalcula alturas e aplica rotações em todos os ancestrais afetados.
