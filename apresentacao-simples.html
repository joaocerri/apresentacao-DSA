Recursão • Fundamentos

O que é Recursão?

Conceito & Anatomia
Definição & Modos

Uma função que chama a si mesma, direta ou indiretamente, dividindo o problema em instâncias menores.

Direta A própria função invoca a si mesma em seu corpo de execução.
Indireta Uma função chama outra função, que por sua vez chama a primeira novamente.
Estrutura de uma Função
01 Caso Elementar: A condição de parada obrigatória.
02 Solução Elementar: A resposta base trivial que encerra as chamadas.
03 Chamada Recursiva: O passo que aproxima o estado do caso elementar.
Recursão • Análise Crítica

Eficiência & Trade-offs

Stack & Viabilidade
Eficiência & Memória

Menos eficiente que a versão iterativa. A cada chamada, a Stack aloca:

• Parâmetros e Variáveis Locais Dados
• Endereço de Retorno Frame
Risco: A Stack é limitada. Excesso de chamadas gera Stack Overflow.
Quando Usar?
Cuidado Nem todo problema recursivo deve ser resolvido com recursão.
Desvantagem Usa mais recursos e é mais lenta que a versão iterativa.
Quando Usar Quando a versão iterativa for excessivamente complexa (ex.: árvores).

Árvores Balanceadas • Introdução

Árvores AVL

Balanceada vs Degenerada
Objetivo
Auto-balanceamento BSTs que mantêm o balanceamento automaticamente a cada operação.
Evita Degeneração Impedem que a árvore vire uma lista (altura linear).
Operações Eficientes Busca, inserção e remoção mantidas em O(log n).
Balanceada × Degenerada altura: log n × n
◀ Altura baixa, busca rápida Vira uma lista encadeada ▶
Árvores AVL • Balanceamento

Fator de Balanceamento

−1 ≤ FB(n) ≤ 1
A Condição
FB(n) = h(dir) − h(esq)
Balanceado ⇒ −1 ≤ FB ≤ 1
Tolerância A diferença de altura entre as subárvores é no máximo 1.
Níveis Incompletos Não é preciso que os últimos níveis estejam completos.
Desbalanceado: qualquer nó com FB > +1 ou FB < −1.
Balanceada × Desbalanceada FB por nó
◀ Todos os nós com −1 ≤ FB ≤ 1 Raiz viola a condição ▶
Árvores AVL • Cálculo do FB

FB: Cálculo & Interpretação

FB(n) = altura(esq) − altura(dir)
A Fórmula
FB(n) = altura(esq) − altura(dir)
Mede a diferença entre as alturas das subárvores esquerda e direita de um nó.
Interpretação
FB = 0 alturas iguais +1 esq. mais alta −1 dir. mais alta
FB > +1: desbalanceio à esquerda  ·  FB < −1: à direita.
FB = +1 esq. mais alta
h(esq)=2 · h(dir)=1
FB = 0 equilibrada
h(esq)=1 · h(dir)=1
FB = −1 dir. mais alta
h(esq)=1 · h(dir)=2
Árvores AVL • Rotações

Como identificar a Rotação?

Quadro-resumo dos 4 casos
Passo a Passo
1 Calcular o fator de balanceamento do nó.
2 Identificar o lado do desbalanceamento.
3 Verificar o FB do filho desse lado.
4 Escolher rotação simples ou dupla.
5 Atualizar ligações e recalcular alturas e fatores.
Os 4 Casos
LL Rotação simples → direita
RR Rotação simples ← esquerda
LR Rotação dupla ← esq, → dir
RL Rotação dupla → dir, ← esq
As rotações AVL restauram o balanceamento sem perder a propriedade de árvore binária de busca.
Árvores AVL • Rotações Simples

Rotações Simples: LL & RR

Antes → Depois
LL • rotação à direita desbalanceada
Condição FB(nó) > +1  e  FB(filho esq.) ≥ 0
C com FB=+2. Clique para rotacionar.
RR • rotação à esquerda desbalanceada
Condição FB(nó) < −1  e  FB(filho dir.) ≤ 0
A com FB=−2. Clique para rotacionar.
O filho está pesado no mesmo sentido do desbalanceamento — uma única rotação corrige.
Árvores AVL • Rotações Duplas

Rotações Duplas: LR & RL

Duas rotações encadeadas
LR • esquerda → direita etapa 0 / 2
Condição FB(nó) > +1  e  FB(filho esq.) < 0
C com FB=+2 e filho A com FB<0. Precisa de 2 rotações.
RL • direita → esquerda etapa 0 / 2
Condição FB(nó) < −1  e  FB(filho dir.) > 0
A com FB=−2 e filho C com FB>0. Precisa de 2 rotações.
O filho está pesado no sentido oposto ao desbalanceamento — exige duas rotações.
Árvore Binária de Busca • Remoção

Remoção em BST

Três casos
Casos de Remoção
Nó Folha Remover diretamente (não tem filhos).
Um Filho Substituir o nó pelo seu único filho.
Dois Filhos Substituir pelo maior valor da subárvore esquerda (antecessor) e remover o nó original desse valor.
Regra de substituição: o antecessor em ordem é o maior valor à esquerda.
Remover 50 (dois filhos) antes
40 (maior da subárvore esquerda) substitui o 50.
Remoção em BST • Caso 1

Remover um Nó Folha

left == NULL && right == NULL
Condição & Procedimento
left == NULL && right == NULL
1 Liberar a memória com free().
2 Retornar NULL.
3 O ponteiro do pai passa a apontar para NULL.
Remover o nó 10 (folha) free(10)
Nó 10 liberado; 20→esquerda vira NULL.
Remoção em BST • Caso 2

Remover um Nó com Um Filho

O filho assume a posição
Condição & Procedimento
Condição O nó possui apenas um filho (esquerdo ou direito).
1 Guardar o ponteiro do filho em uma variável temporária.
2 Liberar a memória do nó removido.
3 Retornar o ponteiro do filho — o pai passa a apontar direto para ele.
Remover o nó 10 (um filho) 15 sobe
15 assume a posição do 10, preservando a ordenação.
Remoção em BST • Caso 3

Remover um Nó com Dois Filhos

Predecessor em ordem
Maior Valor da Subárvore Esquerda
1 Entrar na subárvore esquerda do nó.
2 Avançar sempre à direita até o maior valor.
3 Copiar esse valor para o nó a ser removido.
4 Remover recursivamente o nó original do valor copiado.
Esse valor é o predecessor em ordem. Alternativa: menor da subárvore direita (sucessor).
Remover 50 → predecessor esq, depois → →
O valor 48 é copiado para o nó 50; o 48 original é removido.
Remoção em BST • Código em C

Implementação: remover nó

Recursiva & completa
remove.c BST
1node* removeNode(int num, node *n) {
2 if (n == NULL) return NULL;
3
4 if (num < n->number)
5 n->left = removeNode(num, n->left);
6 else if (num > n->number)
7 n->right = removeNode(num, n->right);
8 else {
9 // caso 2: sem filho esquerdo
10 if (n->left == NULL) {
11 node *temp = n->right;
12 free(n); return temp;
13 } else if (n->right == NULL) {
14 node *temp = n->left;
15 free(n); return temp;
16 }
17 // caso 3: maior da subárvore esquerda
18 node *temp = n->left;
19 while (temp->right != NULL)
20 temp = temp->right;
21 n->number = temp->number;
22 n->left = removeNode(temp->number, n->left);
23 }
24 return n;
25}
Mapa do Código
L2 Caso base: árvore vazia retorna NULL.
L4–7 Busca: desce à esquerda/direita comparando com num.
L10–16 Achou: nó com 0 ou 1 filho — devolve o filho (ou NULL).
L18–22 Dois filhos: pega o maior da esquerda, copia e remove recursivamente.
L24: retorna n — religando a subárvore ao pai a cada nível.

Árvores AVL • Aplicando as Rotações

Do printf à Rotação Real

4 métodos
De Diagnóstico para Correção
Antes O printf apenas identificava qual rotação era necessária.
Agora Métodos que reorganizam os ponteiros e aplicam a rotação de fato.
Padrão Cada método recebe o nó, religa a, b (e c), chama calculateFB() e retorna a nova raiz.
Os 4 Métodos
LL rotateRight() → dir
RR rotateLeft() ← esq
LR rotateLeftRight() ← esq, → dir
RL rotateRightLeft() → dir, ← esq
Cada rotação atualiza o FB da subárvore via calculateFB() e devolve a nova raiz ao chamador.
